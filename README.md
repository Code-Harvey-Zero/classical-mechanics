An Orbital Physics simulation for two bodies, a current work in progress, currently uses vectors, equations of motion (suvat), and for loops to imitate integration (Euler-Cromer integration).
Displayed inside a tkinter GUI, GUI will be upgraded.
currently working towards implementing a better form of integration either velocity verlet or RK4, with the final goal being an optimised N-body simulator.
